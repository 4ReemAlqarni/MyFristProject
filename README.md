# SmartCoach ⚽

An AI-powered football player performance analysis system.

## 📌 Overview
SmartCoach uses machine learning to analyze football player performance and estimate player readiness and fatigue.

## 🎯 Objectives
- Analyze player performance.
- Estimate fatigue and readiness.
- Support data-driven coaching decisions.

## 🛠️ Technologies
- Python
- Pandas
- Scikit-learn
- Streamlit

## 📊 Machine Learning Models
- Decision Tree
- K-Nearest Neighbors (KNN)
- Random Forest
- K-Means Clustering

## 🚀 How to Run
1. Clone this repository.
2. Install the required dependencies.
3. Run the application.
